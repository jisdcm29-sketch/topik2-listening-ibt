# TOPIK II 듣기 문항 선택 연습 전용 일시정지 step05

## 수정 대상
- listening-test/listening-test.js

## 수정 내용
- 문항 선택 연습(question-practice) 모드에서만 하단 오디오 상태 버튼을 클릭하여 일시정지/다시 재생이 가능하도록 수정
- 일시정지 시 오디오, 대기/풀이 카운트다운, 전체 남은 시간 타이머를 함께 정지
- 다시 재생 시 멈춘 지점부터 재개
- 실전시험, 레벨테스트, 랜덤시험, 오답 다시 풀기에서는 기존 자동 재생 동작 유지

## 확인 주소
http://localhost:5500/listening-test/index.html?v=question_practice_pause_step05

## 확인 사항
1. 문항 선택 연습에서 유형을 선택하고 시험 시작
2. 하단 파란 버튼이 재생 중에는 "일시정지"로 표시되는지 확인
3. 클릭하면 "다시 재생"으로 바뀌고 오디오/타이머가 멈추는지 확인
4. 다시 클릭하면 멈춘 지점부터 재생되는지 확인
5. 50문항 실전시험과 레벨테스트에서는 일시정지 기능이 활성화되지 않는지 확인
