# TOPIK II Listening Step07 - 인증 후 시험 시작 강제

작업일: 2026-08-22

## 수정 목적

인증 전에도 `시험 시작` 버튼이 활성화되어 시험이 시작되는 문제를 수정했습니다.

## 수정 파일

- listening-test/listening-test.js

## 수정 내용

1. `updateStartButton()`에서 시험지 선택 여부뿐 아니라 `state.isAuthenticated`도 함께 확인합니다.
2. `handleAuth()`에서 인증 성공/실패 후 시작 버튼 상태를 즉시 갱신합니다.
3. `startExam()` 시작 부분에 최종 안전장치를 추가했습니다.
   - 인증 전이면 시험을 시작하지 않습니다.
   - `인증 후 시험을 시작할 수 있습니다.` 안내를 표시합니다.
   - 비밀번호 입력칸으로 포커스를 이동합니다.

## 영향 범위

- 일반 50문항 실전시험
- 레벨테스트
- 랜덤 시험
- 문항 선택 연습

## 제외 범위

- 진단 보고서에서 들어가는 오답 다시 풀기 직접 흐름은 기존대로 유지합니다.
